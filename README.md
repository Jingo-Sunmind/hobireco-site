# hobireco-site

趣味の台帳アプリ「ホビレコ」の法務ページ（プライバシーポリシー・利用規約・サポート）を GitHub Pages で公開するためのリポジトリです。

公開 URL: https://jingo-sunmind.github.io/hobireco-site/

| ページ | URL |
|---|---|
| プライバシーポリシー | https://jingo-sunmind.github.io/hobireco-site/privacy-policy/ |
| 利用規約 | https://jingo-sunmind.github.io/hobireco-site/terms/ |
| サポート・お問い合わせ | https://jingo-sunmind.github.io/hobireco-site/support/ |

## 原本について

文面の**原本**は、アプリ本体のリポジトリ（非公開）`hobireco-app` の `docs/legal/` にあります。このリポジトリの各ページは、その原本をそのままコピーしたものです。文面を直すときは、原本を直してから、このリポジトリの同じ名前のファイルに同じ内容をコピーして push してください（push すると数分で公開ページに反映されます）。
